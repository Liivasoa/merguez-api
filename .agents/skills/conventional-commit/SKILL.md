# Conventional commits

Inspect the status and relevant diff, preserve unrelated changes, and stage only the changes belonging to the requested commit. Use `type(scope): description`, for example `feat(group): add session`, with a concise imperative description. Add a body or breaking-change footer when useful. Verify the resulting commit and report its hash. Create commits only when authorized by the user or required by current instructions. Do not add a Copilot attribution for Codex work.

For the original examples and details, consult `.github/skills/conventional-commit/SKILL.md`; its Copilot-specific automation does not apply.
